# Civic Issue - Administrator Guide

## Overview

Administrators manage incoming civic reports, coordinate responses, and monitor resolution progress.

## Dashboard

The administration dashboard provides:

- Report overview
- Priority issues
- Status tracking
- Analytics and history

## Managing Reports

1. Open the incident queue.
2. Review citizen descriptions and evidence.
3. Verify location and category.
4. Assign responsible teams.
5. Update the report status.

## Status Workflow

Recommended workflow:

- Submitted: New citizen report received.
- Acknowledged: Report reviewed.
- Assigned: Responsibility allocated.
- In Progress: Work has started.
- Resolved: Action completed.
- Citizen Approved: Citizen confirmed resolution where applicable.

## Evidence Review

Administrators can review attached photos, audio notes, and citizen descriptions before taking action.

## Best Practices

- Keep statuses updated.
- Add meaningful resolution notes.
- Review duplicate reports.
- Protect citizen information.
